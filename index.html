AI IMAGE

为了最后形成 AI 图像提示词，还需要想清楚什么？

SUBJECT

先把画面里的东西说清楚。

YOU ALREADY HAVE
  • 最主要的视觉主体是什么？
  • 主体具体位于哪里？
  • 是否还有第二个重要元素？
  • 两个元素之间是什么关系？
  • 哪个材质或表面状态最值得强调？

CAMERA

决定观众从哪里看这一幕。

  • 特写、近景、中景还是远景？
  • 正面、俯视、平视、低机位还是贴近表面？
  • 镜头距离主体多近？
  • 主体位于中央还是偏离中心？
  • 是否需要大面积留白？
  • 背景清晰还是虚化？

LIGHT

决定材质、颜色和空间如何被看见。

  • 光从哪个方向进入？
  • 柔光还是硬光？
  • 主色调是什么？
  • 背景是什么颜色或材质？
  • 哪些表面需要透光、反光或形成阴影？
  • 整体更接近写实、冷静、电影感、标本感还是超现实？
READY TO WRITE

STILL LIFE

思考这件事情现实中怎么做出来、怎么拍。

MATERIAL

先判断哪些元素真的可以被做出来。

  • 哪些词可以直接变成真实道具？
  • 哪些需要寻找替代材料？
  • 哪些词只是状态，而不是实物？
  • 哪些部分需要透明、柔软、潮湿、反光、粗糙或易变形？
  • 是否需要水、玻璃、纸张、薄膜、纱、金属等辅助材料？
TRANSPARENCYWEIGHTSURFACESOFT / HARDSUPPORTSTABILITY

SETUP

把动作变成一个可以停住的瞬间。

  • 主体应该放在哪里？
  • 什么东西承载另一个东西？
  • 是否需要悬挂、堆积、浸泡、倾斜、包裹或固定？
  • 动态词怎样转化为一个静止瞬间？
  • 哪些痕迹应该真实制作？
  • 是否存在会穿帮的支架、鱼线、胶或支撑结构？

SHOOT

最后决定镜头与光线。

  • 特写、近景还是完整静物？
  • 相机高度与主体是什么关系？
  • 顶光、侧光、逆光还是正面柔光？
  • 是否需要柔光屏？
  • 是否需要反光板或黑旗？
  • 景深应该浅还是深？
  • 哪个局部必须最清楚？
BEFORE YOU SHOOT

先确认：材料可以实现、关系看得见、光线突出核心元素。

SET DESIGN

把当前构想从桌面级画面扩大为空间关系。

SPACE

先决定这件事发生在哪里。

  • 是房间、棚内、街道、仓库还是抽象空间？
  • 主体在中央、边缘还是角落？
  • 场景是否需要墙面、地面、入口、出口或高度关系？
  • 镜头 / 观众从哪里进入？
  • 第一眼应该看到什么？

SCALE

改变尺度和数量。

  • 哪个元素可以被放大？
  • 哪个元素可以缩小？
  • 单个物体能否大量重复？
  • 原本桌面大小的东西能否变成人体尺度？
  • 是否需要让某个元素占领整个空间？
  • 是否可以向画面外继续延伸？

BUILD

考虑它真的如何存在。

  • 需要什么支撑结构？
  • 哪些东西悬挂、堆叠、包裹、穿过或铺开？
  • 使用什么真实材料搭建？
  • 哪些材料需要透光或反光？
  • 光线是否也成为空间结构的一部分？
  • 人能进入其中，还是只能从外部观看？
BUILD THE RELATION

不要只是把物件放进空间，让它们真正改变空间。
